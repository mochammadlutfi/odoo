Data Exchange Suite

Streamline data exchange between Odoo and external tools like Excel, Google Sheets, Notion, or Markdown editors. All clipboard operations work entirely in-browser with no server calls.

Features

  • Copy list data — Adds Copy items to the cog menu of every list view. Supports TSV, CSV, Markdown Table, and JSON formats. If rows are selected, only those rows are copied; otherwise all visible rows are copied.
  • Copy record URL — Ctrl+click (or Cmd+click on Mac) any breadcrumb item to copy the current page URL to the clipboard.
  • Double-click field copy — Double-click any read-only field value in a form view to instantly copy its text. A brief green flash confirms the copy.

Configuration

Go to Settings › Data Exchange to:

  • Enable or disable the double-click copy feature.
  • Set the default copy format for list views.
