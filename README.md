# Odoo 18 — Free Modules

Open-source Odoo 18 modules licensed under **LGPL-3**.

## Modules

| Module | Category | Description |
|---|---|---|
| `ld_dark_mode_pro` | Extra Tools | Dark mode toggle for Odoo backend |
| `ld_data_exchange` | Productivity | Data import/export utilities |
| `ld_env_ribbon_pro` | Technical | Environment ribbon indicator (dev/staging/prod) |
| `ld_pdf_preview_pro` | Productivity | Inline PDF preview |
| `ld_quick_search` | Productivity | Global quick search bar |
| `ld_web_favicon_pro` | Website/Configuration | Customize backend favicon per database |
| `ld_whatsapp_quick_chat` | Productivity | Send WhatsApp message from any record |

## Installation

```bash
# Clone into your Odoo addons path
git clone -b v18 git@github.com:mochammadlutfi/odoo.git custom-addons

# Add to odoo.conf
addons_path = /path/to/odoo/addons,/path/to/custom-addons
```
