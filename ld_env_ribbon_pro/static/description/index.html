Environment Ribbon Pro

Never accidentally edit production again.
A bold, always-visible ribbon — configurable entirely from the Settings UI.

The Problem

You manage five browser tabs — dev, staging, UAT, production, demo. Every single one looks identical.

One wrong click and you just deleted a real customer's sales order, confirmed a draft invoice, or reset a configuration that took hours to set up.

The OCA web_environment_ribbon exists, but it requires editing odoo.conf, has hardcoded colors, and cannot be dismissed by users.

The Solution

One setting. Instant visual clarity. No config file editing required.

Key Features

Config via Settings UI

Everything configured from Settings → Environment Ribbon. No odoo.conf editing. No server restart. Works for non-technical admins.

6 Preset Color Environments

DEV → Blue. STAGING → Orange. UAT → Purple. PRODUCTION → Red. DEMO → Gray. TEST → Green. Plus custom hex color support.

Per-User Dismiss

Users click × to hide the ribbon for the day. It reappears automatically the next morning. Dismiss is always disabled on Production — a non-negotiable safety net.

Auto-Detect ODOO_ENV Variable

Set ODOO_ENV=production on your server and the ribbon auto-configures. Supports: dev, staging, uat, production, demo, test.

4 Ribbon Styles × 4 Positions

Bar (flat edge), Corner (classic 45° fold), Vertical (sideways on the edge), Banner (full-width top/bottom). Each available in top-right, top-left, bottom-right, or bottom-left. Floats above all UI without blocking any navigation buttons.

Production Access Audit Log

Every session on a Production environment is logged: who accessed it, when, and from which IP address. View at Settings → Environment Ribbon → Production Access Log.

Environment Presets

Each environment type has an immediately recognizable color — no need to read the text. The Production ribbon is permanently red and non-dismissable.

How It Works

Config stored in ir.config_parameter. Injected into session_info once per page load (<5ms overhead). The ribbon is an OWL 2 component in the main_components registry. Dismiss state lives in localStorage — no server calls.

ODOO_ENV Values

ODOO_ENV=dev → Development (blue)
ODOO_ENV=staging → Staging (orange)
ODOO_ENV=uat → UAT (purple)
ODOO_ENV=production → Production (red)
ODOO_ENV=demo → Demo (gray)
ODOO_ENV=test → Test (green)
