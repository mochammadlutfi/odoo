Environment Ribbon Pro

Never confuse Production with Staging again.
A crystal-clear colored ribbon on every backend page — DEV, STAGING, UAT, PROD.

The Problem

Your team manages multiple Odoo instances — production, staging, UAT, development. Every screen looks identical. One wrong click and you just deleted a real customer record, not a test record.

A ribbon solves it. But a ribbon should be configurable via the UI, support your brand, never hide the toolbar, and make Production impossible to dismiss. That is what this module does.

One Ribbon per Environment

Key Features

Config via Settings UI

Everything configured from Settings → Environment Ribbon. No odoo.conf editing. No server restart. Works for non-technical admins.

6 Preset Color Environments

DEV → Blue. STAGING → Amber. UAT → Purple. PRODUCTION → Red. DEMO → Gray. TEST → Green. Plus custom hex color support for your own conventions.

Per-User Dismiss

Users click × to hide the ribbon for the day. It reappears automatically the next morning. Dismiss is always disabled on Production — a non-negotiable safety net.

Auto-Detect ODOO_ENV Variable

Set ODOO_ENV=production on your server and the ribbon auto-configures. Supports: dev, staging, uat, production, demo, test.

4 Ribbon Styles × 4 Positions

Bar (straight edge), Corner (diagonal fold), Vertical (sideways), Banner (full width). Each available in top-right, top-left, bottom-right, or bottom-left.

Production Access Audit Log

Every session on a Production environment is logged: who accessed it, when, and from which IP address. View at Settings → Environment Ribbon → Production Access Log.

Simple Settings UI

Every option lives in one place. Non-technical admins can configure everything without touching a config file.

Up and Running in 60 Seconds

Open Settings

Go to Settings and click Environment Ribbon.

Pick Environment

Choose DEV / STAGING / UAT / PROD / DEMO / TEST from the dropdown.

Save

Click Save. The ribbon appears instantly — no server restart.

Done

Every backend page now shows the ribbon. No more misclicks.
