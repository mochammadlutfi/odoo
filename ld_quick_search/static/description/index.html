Ctrl+K for Odoo

Jump to any menu, action, or record in 200 ms.

Press Ctrl+K anywhere in Odoo
invnum → Invoicing / Customer Invoices
@res.partner john → John Doe (Contact)
> new purchase order → Create: Purchase Order

Why you'll want it

  • Fuzzy search — typo tolerant. fakturr still finds Invoices.
  • Four search modes — menus, actions (>), settings (#), records (@model).
  • Recent & Favorites — your most-used destinations bubble to the top.
  • Keyboard-only — ↑ ↓ Enter Esc. No mouse needed.
  • Respects ACL — never leaks records users can't read.
  • Free forever, LGPL-3.

Security model

The search engine runs every query as the calling user. On any access failure it fails closed, returning an empty list — so no record IDs are ever leaked to a user who cannot read them. Admins can additionally whitelist or blacklist models from Settings → Quick Search.
